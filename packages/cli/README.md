# CommandThing CLI

The `commandthing` package configures and diagnoses a CommandThing installation.

The package is not published yet. Inside the repository, use:

```bash
pnpm commandthing setup hooks
pnpm commandthing config init
pnpm commandthing doctor
pnpm commandthing remove hooks
```

After the first public release, the equivalent setup command will be:

```bash
npx commandthing@latest setup hooks
```

See the repository's `docs/cli.md` for command details and safety behavior.
