# Brand assets

The provider marks in the Usage overview are pinned static SVGs so the offline Car Thing dashboard
does not depend on a CDN.

| Asset | Source | Catalog version |
|---|---|---|
| Claude | <https://cdn.jsdelivr.net/npm/simple-icons@15.0.0/icons/claude.svg> | Simple Icons 15.0.0 |
| OpenAI | <https://cdn.jsdelivr.net/npm/simple-icons@15.0.0/icons/openai.svg> | Simple Icons 15.0.0 |
| OpenCode | <https://github.com/anomalyco/opencode/blob/849c2598abc7d2b40261e74b5826bc74ffc78308/packages/console/app/src/asset/brand/opencode-logo-dark-square.svg> | Official repository, pinned commit |

Simple Icons publishes the catalog under CC0 1.0, but its license does not waive third-party
trademark rights. Provider names and logos remain the property of their respective owners. Keep the
marks monochrome, undistorted, and subordinate to CommandThing's own identity. Review the current
[OpenAI brand guidelines](https://openai.com/brand/) before changing the OpenAI mark.

The OpenCode mark is copied unchanged from its official MIT-licensed repository and pinned to an
exact commit so builds do not drift when upstream assets change.
